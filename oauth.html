Tootsville OAuth Configuration Guide

🚨 Critical Setup Required

This guide contains the complete OAuth configuration needed to enable user authentication in Tootsville. Without these configurations, users cannot sign in with GitHub, Microsoft, Apple, Yahoo, or Bluesky.

Overview

Tootsville supports authentication through multiple OAuth providers:

  • GitHub - Most popular for developers
  • Microsoft - Enterprise users
  • Apple - iOS/macOS users
  • Yahoo - Email service users
  • Bluesky - Social media platform

Current Status: All OAuth providers are failing with "identity provider configuration not found" errors. This is blocking user authentication.

Prerequisites

Before starting, ensure you have:

  • Firebase project created and configured
  • GitHub account with repository admin access
  • Microsoft Azure subscription (free tier available)
  • Apple Developer Program membership ($99/year)
  • Yahoo Developer account
  • Domain ownership verification for production URLs

GitHub OAuth Setup

🐙 GitHub OAuth App Configuration

1 Access GitHub OAuth Apps

Go to GitHub Developer Settings

2 Create New OAuth App

Click "New OAuth App" and fill in:

Application name: Tootsville Game Homepage URL: https://tootsville.org Application description: Tootsville multiplayer game authentication Authorization callback URL: https://tootsville.org/play/
3 Copy Credentials

After creation, copy the Client ID and Client Secret

4 Configure in Firebase

Add the credentials to Firebase Console → Authentication → Sign-in method → GitHub

GitHub Permissions: The OAuth app requires no special permissions for basic authentication.

Microsoft Azure Setup

🪟 Microsoft Azure App Registration

1 Access Azure Portal

Go to Azure Portal

2 Navigate to App Registrations

Search for "App registrations" and click "New registration"

3 Configure App Registration
Name: Tootsville Game Supported account types: Accounts in any organizational directory and personal Microsoft accounts Redirect URI: - Type: Web - URI: https://tootsville.org/play/
4 Create Client Secret

Go to Certificates & secrets → New client secret

Description: Tootsville Game Authentication Expires: 24 months (recommended)
5 Copy Credentials

Copy Application (client) ID and Client Secret value

6 Configure in Firebase

Add credentials to Firebase Console → Authentication → Sign-in method → Microsoft

Apple Developer Setup

🍎 Apple Sign In Configuration

Apple Developer Program Required: This requires an active Apple Developer Program membership ($99/year).

1 Access Apple Developer Console

Go to Apple Developer Console

2 Create Services ID

Navigate to Certificates, Identifiers & Profiles → Identifiers

Click "+" → Select "Services IDs" Description: Tootsville Game Authentication Identifier: org.tootsville.game
3 Enable Sign In with Apple

Select your new Services ID and enable "Sign In with Apple"

4 Create Private Key

Go to Keys section and create a new key:

Key Name: Tootsville Auth Key Enable: Sign In with Apple Configure: Select your Services ID (org.tootsville.game)
5 Download Key

Download the .p8 file and store it securely

6 Configure in Firebase
Team ID: YOUR_APPLE_DEVELOPER_TEAM_ID Services ID: org.tootsville.game Private Key: Contents of downloaded .p8 file

Security Note: Keep the private key file secure and never commit it to version control.

Redirect URIs Configuration

For ALL OAuth providers, configure these redirect URIs:

Development Environment:

  • http://localhost:5000/play/

Production Environment:

  • https://tootsville.org/play/

Test Environment:

  • https://test.tootsville.org/play/

Important: All redirect URIs must be configured in each OAuth provider's settings and must exactly match the URLs used in your application.

Troubleshooting

Common Issues

🔴 "Identity provider configuration not found"

Cause: OAuth provider not configured in Firebase

Solution: Enable provider in Firebase Console and add credentials

🔴 "Invalid redirect URI"

Cause: Redirect URI mismatch

Solution: Ensure exact URI match in OAuth provider settings

🔴 "Popup blocked by browser"

Cause: Browser popup blocker

Solution: Allow popups for the domain or use redirect flow

🔴 Apple "Configuration not found"

Cause: Apple Developer Program not active or Services ID misconfigured

Solution: Verify Apple Developer membership and Services ID setup

Debug Tools

  • Check browser developer console for detailed error messages
  • Verify Firebase Console authentication settings
  • Test OAuth provider configurations individually
  • Use Firebase Authentication emulator for local testing
